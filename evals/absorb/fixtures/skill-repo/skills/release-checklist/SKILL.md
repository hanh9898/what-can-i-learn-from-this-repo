Walk the maintainer through publishing a new edition, one step at a time. Ask before moving to the next step.

## Steps

1. Confirm the edition number and the date it goes out.
2. Read every note changed since the last edition and check it against the rules table below.
3. Check every term used in the changed notes against the glossary below.
4. Build the table of contents by hand from the note titles.
5. Write the edition's changelog: one line per changed note.
6. Ask the maintainer to approve the changelog.
7. Tag the edition in git and tell the maintainer to upload it.
